# Reports

CTO status reports, incident write-ups, and audit trails.

## Naming

```
YYYY-MM-DD-<topic>.md
```

Use [`TEMPLATE-weekly-status.md`](TEMPLATE-weekly-status.md) for recurring summaries.

## Rules

- Facts only — no invented metrics or "all green" without evidence
- Link to checklist items in [`docs/OS-BRINGUP-CHECKLIST.md`](../../docs/OS-BRINGUP-CHECKLIST.md)
- Redact secrets and customer full names
